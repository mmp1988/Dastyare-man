دستیار من - بسته نهایی Mina-Msvm
================================================

فایل‌های موجود در این بسته:
- index.html : رابط کاربری فارسی و کامل (نوبت‌ها، لیست ترمیم، ارسال سریع پیام به مشتری و تنظیمات نمایش قیمت/بیعانه/مانده حساب، بدون رمز یا قفل کاربری)
- manifest.json : تنظیمات نصب و نمایش برنامه
- sw.js : مدیریت کش و به‌روزرسانی نسخه
- icon-192.png و icon-512.png : آیکون‌های برنامه
- README.txt : این فایل راهنما
