راهنمای انتشار اپلیکیشن «دستیار من» روی گیت‌هاب، نتلیفای و ساخت APK:

1. تمام فایل‌های داخل این پوشه (index.html, manifest.json, sw.js, icon-192.png, icon-512.png) را در یک مخزن جدید در GitHub آپلود کنید.
2. مخزن را به Netlify متصل کنید تا لینک مستقیم (HTTPS) بسازد.
3. کاربران آیفون با باز کردن لینک در Safari و زدن Share -> Add to Home Screen می‌توانند برنامه را نصب کنند.
4. کاربران اندروید با باز کردن لینک در Chrome و زدن Install App برنامه را نصب می‌کنند.
5. برای دریافت فایل .apk اندروید: لینک سایت Netlify را در سایت رایگان https://www.pwabuilder.com وارد کرده و خروجی Android APK دانلود کنید.
