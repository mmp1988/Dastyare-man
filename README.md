# دستیار من

اپ اندرویدی مستقل پروژه دستیار من.

## نسخه اندروید مستقل
- رابط برنامه داخل Android WebView اجرا می‌شود و برای بازشدن برنامه نیازی به Chrome یا بازکردن سایت نیست.
- فایل‌های اصلی برنامه همراه APK نصب می‌شوند و برنامه در حالت آفلاین هم اجرا می‌شود.
- داده‌های برنامه در فضای خصوصی خود اپ اندروید ذخیره می‌شوند؛ پوشه‌های داخلی `content`، `data`، `backups` و `updates` جدا هستند.
- نسخه پشتیبان داخلی هنگام ذخیره اطلاعات به‌روزرسانی می‌شود. از بخش پشتیبان‌گیری می‌توان فایل JSON را در پوشه دلخواه گوشی ذخیره کرد و بعداً بازیابی کرد.
- مجوز میکروفن، دوربین و مکان فقط وقتی قابلیتی به آن نیاز داشته باشد درخواست می‌شود. انتخاب فایل از پنجره امن Android انجام می‌شود و دسترسی عمومی به تمام حافظه درخواست نمی‌شود.
- دکمه به‌روزرسانی داخل برنامه، نسخه جدید صفحه و منطق برنامه را دریافت می‌کند و داده‌ها را نگه می‌دارد. تغییرات کد اندروید یا مجوزهای جدید همچنان به APK جدید نیاز دارند.

## انتقال اطلاعات از نسخه قبلی وب/PWA
اطلاعات نسخه قبلی مرورگر به‌صورت خودکار در فضای خصوصی اپ جدید قابل خواندن نیست. پیش از کنارگذاشتن نسخه قبلی:
1. نسخه قدیمی را باز کنید و از تنظیمات، «دانلود فایل پشتیبان» را بزنید.
2. APK جدید را نصب و اجرا کنید.
3. در برنامه جدید از «بازیابی فایل پشتیبان» همان فایل JSON را انتخاب کنید.
4. پس از بررسی اطلاعات، نسخه قدیمی را کنار بگذارید.

## ساخت APK امضاشده
Workflow فایل `.github/workflows/build-native-apk.yml` برای انتشار امن به چهار GitHub Actions secret نیاز دارد:
- `ANDROID_KEYSTORE_BASE64`
- `ANDROID_KEYSTORE_PASSWORD`
- `ANDROID_KEY_ALIAS`
- `ANDROID_KEY_PASSWORD`

کلید امضای ثابت را محرمانه نگه دارید و آن را در مخزن عمومی یا چت قرار ندهید. بدون این secrets فقط APK آزمایشی بدون امضا ساخته می‌شود و به‌عنوان نسخه قابل نصب منتشر نمی‌شود.
